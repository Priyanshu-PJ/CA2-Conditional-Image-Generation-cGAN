# Class-Controlled MNIST Generation using cGAN

## Run
Open `CA2_cGAN_MNIST.ipynb` in Google Colab, select GPU if available, and run all cells. MNIST is downloaded by torchvision. Output files are saved in `/content/cgan_results`.

## Architecture
Conditional convolutional GAN using class embeddings in both generator and discriminator. Generator input is a 100-dimensional noise vector and digit class.

## Evaluation
Generated digit grids, adversarial loss plots, and a separate CNN classifier agreement proxy (with real test accuracy reported). Results must be generated by running the notebook.

## Requirements
PyTorch, torchvision, numpy, matplotlib (standard Colab environment).

## Limitations
Training varies by hardware and seed; classifier agreement does not fully measure image quality or diversity.
